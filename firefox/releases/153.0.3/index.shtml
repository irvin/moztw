Firefox 新鮮事

  • 全新功能

    包含多項 智慧視窗 改進：

    • 建議清單現在顯示更多結果，更容易找到瀏覽記錄與切換至已開啟的分頁。（Bug 2019042）
    • 助手現在可直接使用 Exa 的網路搜尋結果回答問題，不再轉交給搜尋引擎。（Bug 2046183、Bug 2044385）

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 修正

    修正從 Blob URL 載入媒體的網站上，音訊與視訊無法播放，或跳轉播放位置時卡住的問題。（Bug 2056444）

  • 修正

    修正從 Firefox 拖曳到 Windows 桌面的網路捷徑被標記為不受信任，導致每次開啟都出現安全性警告的問題。（Bug 2056865）

  • 修正

    修正當側邊欄隱藏且密碼管理員被企業政策停用時，書籤、瀏覽記錄及其他側邊欄無法開啟的問題。（Bug 2056857）

  • 修正

    修正 Mozilla VPN 升級優惠在未販售 Mozilla VPN 的地區顯示的問題。（Bug 2058264）

  • 修正

    修正在擴充套件內容腳本新增事件監聽器的頁面上，開發者工具檢查器頻繁當機的問題。（Bug 2042101）

  • 修正

    修正 Windows 上在部分更新仍套用時啟動 Firefox，可能讓安裝損壞且無法啟動的罕見問題。（Bug 2058197、Bug 2058594）

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
