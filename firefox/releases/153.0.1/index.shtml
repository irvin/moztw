Firefox 新鮮事

  • 修正

    修正 Firefox 更新後，部分應用程式內部檔案無法載入，可能導致 Firefox 在 Windows 上啟動時當機的問題。Firefox 現在應可在這些情況下啟動，但在後續更新完成前，部分介面可能無法正確顯示。（Bug 2056926）

  • 修正

    修正在部分音樂與音訊串流網站上，暫停並繼續播放後音訊變成無聲的問題。（Bug 2053586）

  • 修正

    修正使用自訂桌布時，新分頁載入幾秒後背景閃爍的問題。（Bug 2056650）

  • 修正

    修正頁面載入使用 javascript: 位址的框架時可能發生當機的問題。（Bug 2054485）

  • 修正

    修正在頁面的可編輯區域輸入文字時可能發生當機的問題。（Bug 2053867）

  • 修正

    修正你已自行安裝的搜尋引擎，之後 Firefox 開始提供相同引擎時被標示為「新增」的問題。（Bug 2053710）

  • 修正

    改善遊戲與其他沉浸式網路內容使用的指標鎖定，降低滑鼠指標逃離 Firefox 視窗的可能性。（Bug 1255338、Bug 2040628）

  • 修正

    修正檢查器「規則」檢視中，每個選取元素的虛擬元素只能展開一次的問題。（Bug 2054525）

  • 修正

    修正「檢視頁面原始碼」無法載入 blob: 文件的問題。（Bug 2054428）

  • 修正

    修正「檢視頁面原始碼」在繼承來源的文件（例如使用 srcdoc 屬性的框架）上逾時的問題。（Bug 2054487）

已知問題

  • 尚待修復

    部分 Windows 使用者在更新後啟動 Firefox 時可能發生當機，原因是不完整的更新導致 Firefox 安裝處於不一致的狀態。（Bug 1681745）若受到影響，可從 firefox.com 下載 Firefox，並覆蓋安裝到現有的 Firefox 上即可修復。你的書籤、密碼與其他資料會另外儲存，不會受到影響。已於 Firefox 153.0.1 修復。
